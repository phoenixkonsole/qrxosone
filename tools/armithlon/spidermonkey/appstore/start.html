ThunderCat for AROS

A web browser running natively on QRX OS One 64: 64-bit AROS on the 68100EC64. Gecko 153.8 in one process, drawn in software by WebRender, in an Intuition window on the desktop.

Using it

  • Click the address bar (or press Ctrl+L), type an address and press Return.
  • Back, forward and reload are left of the address bar; Alt+←, Alt+→ and F5 do the same.
  • New tab Ctrl+T, close tab Ctrl+W, the menu is the button on the right.
  • The mouse wheel scrolls; the window's corner resizes it, its close gadget ends ThunderCat.
