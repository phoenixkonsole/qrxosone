# QRX OS One Amiga68k v0.20.3.7.4.6.5.9

**QRX Flat Retro UI / ECS-OCS Visual Baseline**

Direct successor to .5.8. The design is flat by intent, but no longer visually unbounded: flat colour fields are separated with crisp classic 1px edges. OCS 2-bit screens get a four-colour high-contrast baseline; ECS/AGA-low uses the existing compact palette mapping; AGA/RTG receives richer QRX blue/cyan shades while preserving the same geometry.

Build with the same reference tar, ReactOS live ZIP and v0.20.1 source root used for .5.8. After boot run `QRX:C/QRXArosAbi02` and then `QRX:C/QRXDesktop`.
