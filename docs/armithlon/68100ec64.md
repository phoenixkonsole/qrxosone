# 68100EC64 instruction set

Version 1, draft. The 68100 with 64-bit registers, addresses and operations, for a 64-bit AROS with
SMP. EC as on the 68EC040: no MMU. Reference code: `upstream/armithlon/2.6/engine/full68k/qrx68100ec64.c`,
tests in `tests/ec64_tests.c` and `tests/ec64_diff_tests.c`.

The existing 68100 and its JIT are unchanged. This core is separate and is not reachable from a guest
yet.

## Modes

| Mode | Registers and addresses | Prefix |
| --- | --- | --- |
| 32-bit (reset) | The 68040's integer instructions | Faults |
| Long | 64 bits | Allowed |

`MOVEC Rn,$80F` sets long mode from bit 0. `MOVEC $80F,Rn` reads it, and `MOVEC $80E,Rn` reads the core
number. See below for supervisor state, exceptions and several cores.

## Registers

D0 to D15 and A0 to A15, 64 bits each, in long mode. A7 is the stack pointer. PC is 64 bits.

## Prefix

Line A was free on the 68k, so the prefix word is `$A0xx`, directly before an ordinary instruction.

| Bit | Name | Meaning |
| --- | --- | --- |
| 4 | N | `MOVE` leaves the flags alone. Other instructions fault with it |
| 3 | W | `.L` becomes `.Q`, 64 bits |
| 2 | R | Adds 8 to the register in bits 11 to 9 (the destination field of `MOVE`) |
| 1 | X | Adds 8 to the index register |
| 0 | B | Adds 8 to the register in bits 2 to 0 |

`$A020` to `$AFFF` are reserved and fault. N exists because a compiler may place a register copy between
a compare and its branch. A stock assembler can write the prefix as a `.word`, see
`guest/ec64/fnv64.S`.

## Long mode rules

- **Operand sizes:** `.B` and `.W` writes to a data register keep the upper bits. `.L` writes clear bits
  63 to 32. `.Q` writes all of it. Clearing avoids a dependency on the old value, which suits the JIT.
- **Flags:** Computed at the operand size.
- **Address registers:** Always 64 bits. `MOVEA.W`, `MOVEA.L`, `ADDA` and `SUBA` sign extend the source.
  Under W they take all 64 bits.
- **`MOVEQ`:** Sign extends to 64 bits.
- **Immediates:** `#imm` under W has 8 bytes.
- **Addressing:** `(xxx).W` and `(xxx).L` sign extend. In `d8(An,Xn.L)` the index is the whole register.
  The 68020 full format works without its memory indirect forms.
- **PC relative destinations:** `(d,PC)` and `(d,PC,Xn)` may be written to in long mode, for all instructions
  with an alterable operand, so that a program can reach its data within 2 GB without a register.
- **Stack:** `JSR`, `BSR`, `RTS`, `PEA`, `LINK` and `UNLK` use 8 bytes.
- **`MOVEM`:** `.L` stores the low half and sign extends on load. Under W it stores all 64 bits.
- **Wide forms under W:** `EXT` from 32 to 64 bits, `SWAP` swaps the halves, `MULU` and `MULS` are 64 x 64 with
  an optional high half, `DIVU` and `DIVS` are 64 / 64. Bit numbers on a data register run to 63, as do
  shift counts.
- **Atomics:** `TAS` and `CAS` up to `.Q` are atomic on aligned addresses, also between host threads. Other
  aligned accesses keep the 68040's bus order.

## Supervisor state and exceptions

In long mode, once VBR has been written, every fault, trap and interrupt goes through the vector table.
Until then a core stops and reports, which the instruction tests rely on.

- **States:** Supervisor and user, with two stack pointers. A core starts in supervisor state.
  `MOVE USP`, `MOVEC $800`, `RTE`, `STOP`, `RESET`, `MOVE to SR`, `ANDI`, `ORI` and `EORI to SR`,
  `MOVE from SR` and every `MOVEC` are privileged.
- **Vector table:** 256 entries of 8 bytes at VBR (`MOVEC $801`), 8-byte aligned. The vector numbers are the
  68000's: 2 bus fault, 4 illegal, 5 divide by zero, 6 CHK, 7 TRAPV and TRAPcc, 8 privilege, 10 line A (a
  reserved prefix), 11 line F, 24 + n interrupt level n, 32 + n `TRAP #n`.
- **Frame:** SR (2 bytes), format and vector offset (2), reserved (4), PC (8). Format 1 adds the fault address
  (8). `RTE` reads the format.
- **Which PC:** Faults, illegal and privilege give the instruction's own address, traps the next one. A bus
  fault does not undo the instruction's address register updates: there is no MMU and so no restart.
- **Interrupts:** Seven levels as on the 68000, level 7 cannot be masked. On this machine level 5 is the
  core's timer and level 6 a signal from another core.
- **No exception frame possible:** The core stops with a double fault when the stack or the vector entry is
  outside RAM.

### Control registers

| `MOVEC` | Name | |
| --- | --- | --- |
| `$800` | USP | The user stack pointer |
| `$801` | VBR | Writing it switches exceptions on, in long mode |
| `$80A` | Start stack | Stack for the next core this one starts |
| `$80B` | Cores | Number of cores, read only |
| `$80C` | Timer | Period of this core's timer interrupt in microseconds, 0 is off |
| `$80D` | Signal | Write a mask of cores: each gets a level 6 interrupt |
| `$80E` | Core | This core's number, read only |
| `$80F` | Long mode | Bit 0 |
| `$8F0`, `$8F1` | Console, end | Test machine only: writing `$8F0` puts a character out, reading it takes the next input character or -1; writing `$8F1` ends the run with a value |

### Several cores

Core 0 starts at reset. The others wait. The first signal a waiting core gets starts it: it takes the VBR of
the core that sent the signal, the stack that core named in `$80A`, and long mode, and takes the level 6
interrupt at once. Its frame holds no PC to return to.

Memory between cores follows the 68040's bus order, and `TAS` and `CAS` are atomic.
`qrx68100ec64_machine.c` runs each core on its own host thread.

## Not there yet

- Memory indirect addressing, `MOVE16`, trace, the FPU. `CAS2` is not atomic.
- Bit fields work on at most 32 bits, also in long mode.
- A JIT. The interpreter ran 41 to 77 million instructions per second in the tests, far too slow for a browser.
- The core runs in tests only, not in the emulator.
- Calling 32-bit libraries from long mode or the reverse. A 32-bit AROS program does not run on a 64-bit
  AROS without this.
- The assembler (`llvm-mc`) does not know the privileged instructions yet; they go in as `.short`. A 64-bit AROS boots on the core up to its shell, see [tools/armithlon/aros-qrx](../../tools/armithlon/aros-qrx/README.md).
