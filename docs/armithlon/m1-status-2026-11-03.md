# M1 integration status, 2026-11-03

Original archives and canonical desktop source are preserved. Active app is
`.build/bundle/ARMithlon.app`; writable full ISO tree is `.build/bundle/SystemFull`.
The previous working minimal tree remains `.build/bundle/System`.

Full ISO content now reaches QRXDesktop and launches QRXWelcome. PIPE mount
is deferred because Mount stalls while resolving the ISO DOSDriver; apps that
need PIPE are not yet validated. Full startup used is in
`tools/armithlon/Startup-Sequence-FullISO`. The ISO's native apps still have
palette/contrast problems on the shared 24-bit RTG screen.

HostFS fixes: missing intermediate paths report NOENT, opening a directory
as a file is rejected, and failed Read/Write/Seek keep their -1 result.
Regression tests pass (56/56, outputs/snapshot-2026-11-03/ctest-fast-hook.log).

Input: movement diagnostics removed (they previously caused a HostFS write
and fsync on every motion). Window producer and guest QRXHostInput now use
an event-local 12-bit X and Y in the low 24 bits of type-3 events. Update
both together. Keyboard uses WRITEEVENT to avoid duplicate guest repeat.

Performance: normal instruction hook bypasses diagnostic option checks,
retaining instruction counting, exception history and subcall termination.
A native sample of the real desktop confirms interpreter/bus costs plus
frame conversion and Cocoa overhead; this is NOT a JIT or acceleration proof.
Sample: outputs/snapshot-2026-11-03/desktop-cpu-sample.txt in workspace.

AHI audit: the full AROS runner still has no connected AHI subdriver. The
separate native demo has AudioQueue/ring code, but it is not evidence of
AROS AHI playback. Source reference drivers were extracted to
`.build/aros-reference/.../workbench/devs/AHI/Drivers/` for implementation.
3D mailbox interfaces are not complete OpenGL/DirectX/Glide guest wrappers.
No Amithlon-equivalent performance claim is justified yet.

## Update: Welcome and second disk

QRXWelcome and the five unified system apps have been rebuilt from the
current diagnostics-v6.6 sources with the matching QRX theme. Welcome text,
title and buttons were visually verified readable. Original ISO binaries
are preserved in `.build/bundle/original-iso-apps`.

The native application menu now offers a directory chooser and Finder access
for APPS:. The second guest handler QRXAppsFS uses MMIO FF000840 and is mounted
by the bootstrap. The default host directory is `.build/bundle/Apps`.
Selection is saved in macOS preferences and applies on the next application
start. Menu entries were verified, but the full chooser/persistence and guest
write workflow has not yet been verified end-to-end.

Latest native suite: 56/56 pass (`ctest-menu-apps.log`). Native executable:
`.build/m1-native/qrx68100_full_run`; installed copy:
`.build/bundle/ARMithlon.app/Contents/MacOS/armithlon-engine`.
The app launcher uses the writable `.build/bundle/SystemFull` tree.
Build directories contain absolute paths and must be reconfigured after moving.
AHI and full RTG/3D acceleration remain unfinished as described above.
