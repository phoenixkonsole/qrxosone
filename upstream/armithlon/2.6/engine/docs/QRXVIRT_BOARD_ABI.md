# qrxvirt board ABI v1 (implemented subset)

This file documents the **current synthetic board**, not an Apollo SAGA/68080 register map and not real Amiga chip registers. Its device ABI has not been stabilized for independent implementations.

## Reset & RAM

- Guest address-space width 32-bit. 68k word/long memory accesses are **big-endian**.
- RAM starts at `0x00000000` and extends up to the configured size. Exclude the MMIO hole `0x00FF0000..0x00FF03FF` even if configured RAM size overlaps it.
- At reset: read 32-bit SSP from guest address 0, 32-bit initial PC from address 4. Both are required to be even. `SR=0x2700`, guest vCPU0 starts in supervisor mode, `VBR=0`, vCPU1 offline.
- Exception delivery is currently a simplified `SR.w ; PC.l` six-byte supervisor stack frame, which is **not the actual 68040 exception format**. AROS boot must not rely on this being 68040-compatible.
- `VBR` exists in CPU state but the `MOVEC` access path is not implemented. Interrupt delivery and timer interrupts are not implemented.

## MMIO

| Offset from `0x00FF0000` | Size | Direction | Description |
|---|---|---|---|
| `0x00` | 32 | read | 0x51525831, ASCII `QRX1` |
| `0x04` | 32 | read | `0x00010000`, ABI v1.0 |
| `0x08` | 32 | read | Feature bitmap: 1 UART, 2 timer, 4 shutdown; when media bound: 8 video, 16 audio, 32 input |
| `0x0C` | 8 | write | Debug UART byte; host console callback |
| `0x10` | 32 | read | Monotonic host milliseconds, modulo 2^32 |
| `0x14` | 32 | read | Online 68100 virtual CPUs: 1 |
| `0x18` | 32 | read | Defined virtual CPUs: 2 |
| `0x1C` | 32 | write | Writing 1 requests clean VM shutdown |

Media registers `0x00FF0100..0x00FF0314` are defined in [MEDIA_0_4.md](MEDIA_0_4.md). Every other access faults. Sub-width reads of word registers or wrong-width writes also fault. MMIO alignment is enforced; generic 68020+ RAM data accesses may be unaligned. No host virtual addresses are disclosed.

## Exceptions

Guest illegal instructions: vector 4; unimplemented/inaccessible memory access: vector 2; odd PC: vector 3; privileged op in user mode: vector 8. `TRAP #n` uses vector `32+n`. If no vector exists, the VM halts with a reported fault. A real MC68040 fault format, 68040 MMU, interrupts and precise transactional restart have **not** been implemented.

## Runtime interfaces

Host callbacks in `qrx_vm_set_host()` currently handle UART characters and the monotonic tick provider. There is an implemented fixed framebuffer/MMIO PCM/input device bridge (see [MEDIA_0_4.md](MEDIA_0_4.md)), but **no AROS AHI/graphics.hidd/input.device driver, bsdsocket, storage or 3D transport** yet. The host/guest boundary will later become a versioned bounded command-queue ABI; avoid hardcoding unimplemented queue registers in guest drivers until implemented.

## Boot monitor

At guest PC `0x100`, the program generated by `qrx_build_boot_monitor()` uses `LEA`, `MOVE.B #imm,(A0)` to print the message and `MOVE.L #1,(A0)` to shut down. This proves chipset-less execution of a handcrafted 68k binary, not AROS startup.

## v0.5 addendum (supersedes 0x400 I/O length from v0.4)

The QRXvirt board's MMIO window now extends to **0x00FF07FF**, size 0x800.
Graphics capability bit 6 indicates the new QRXGPU2D mailbox at 0x00FF0400.
Audio DMA capability is part of the existing media device and uses registers
0x00FF0214–0x00FF0220. Precise guest/host formats and range checks are in
[`GPU2D_0_5.md`](GPU2D_0_5.md). This ABI is a development interface and not
SAGA/Voodoo/PCI compatible hardware.
