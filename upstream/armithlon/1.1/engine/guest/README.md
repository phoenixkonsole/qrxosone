This directory contains ONLY the draft guest-facing qrxvirt board constants.
It is NOT an existing AROS HIDD/device driver or a bootable AROS BSP.

The upstream/default AROS amiga-m68k board has Classic Amiga expectations.
A dedicated qrxvirt-m68k build path needs to be brought up against the
actual AROS revision used by QRX OS One. See docs/NEXT_IMPLEMENTATION.md.
